# Story 8.6: Moonlit Village, Mob and Chase Music

Status: done

<!-- Note: Validation is optional. Run validate-create-story for quality check before dev-story. -->

## Story

As a kid,
I want the chase to look goofy-spooky, never scary,
so that it's exciting without giving me nightmares.

## Acceptance Criteria

1. **Moonlit Village replaces every Pitchfork Panic placeholder (FR74, NFR10, NFR13).** The chase runs in the Moonlit Village: a night sky (`night` `Sky` `ColorRect`, as Zombie Run's sky), a static smiling moon, and four parallax layers (night clouds and stars, far hills with house silhouettes and lit windows, the near village street front, the cobbled ground strip) scrolled by the existing camera exactly like Sunny Village Green (`SunnyVillageBackdrop`, same layer names and factors). It matches the 5.0 Pitchfork Panic level card (`tools/gen_ui_art.gd` `_card_pitchfork_panic`: night sky, chalk stars, `art-moon` moon, dusk hills, `ink-muted` houses with `pumpkin-light` windows, a `wood-dark` path). Cute-Halloween: jack-o'-lanterns, friendly bats, lit windows; no horror lighting, no gore, nothing a 6-year-old would find scary.
2. **The mob is 2 base sprites, recoloured (GDD Reuse, FR70).** Four villagers run as one mob: base A carries a pitchfork held **straight up** (never aimed), base B carries a torch; each base has one recolour (a legend swap of the clothes only: same alpha mask, same `ink`). Faces are big, goofy and cartoonish (e.g. villagers woken up in nightcaps), skin `art-skin-light`/`art-skin-dark` only, never zombie green. They run facing right (toward the zombie), 4 frames at 10 fps; the torch flame flickers in the frames. The mob node's origin stays the front member's feet at the logical mob position (`mob_steps * step_px`), so the gap, the catch and the "on screen under 20 steps" rule are unchanged; the other three trail behind within 48 px.
3. **The mob-coming hint is art, not a gradient.** `%MobGlow` (a `GradientTexture2D` alpha strip, off-palette) is replaced by `%MobHint`: a palette sprite of torch flames and pitchfork tips poking in from the left screen edge, sliding in (whole px, no alpha) as the gap closes from 32 to 20 steps, hidden whenever the mob itself is visible. Same strength formula as 8.3.
4. **The ending pieces are sprites (FR73).** The dust cloud, the dizzy stars, the escape bush and a new zombie **dazed** sit replace the 8.5 code-drawn placeholders and the -12° tilt: every one keeps its class and API (`DustCloud.play`, `DizzyStars.start/stop`, `EscapeBush.rustle`, the outro timings), steps frames by whole pixels and frames (never a non-integer scale or a rotation of pixel art), and a missing sprite never stops the run (NFR16). The hat stays on the dazed zombie (anchors).
5. **Every new sheet passes the style tests.** Palette only, hard alpha, 1 px `ink` outline on characters, props and effects, 2–6 frames at 8–12 fps (or tween-stepped like the poof), one ground row per sheet, square frames, Lossless with no mipmaps, never `candy-yellow` or `stamp-red`. Each sheet is listed in `test_art_sprites.gd`, the art review scene and the style sheet table. Backdrop layers keep the backdrop rules (exempt from the outline rule only; hard alpha; palette; no `candy-yellow`/`stamp-red`; 640 px seams wrap) plus a **night readability band** (Dev Notes) so characters never get lost against the dark (deferred story-1-9 note).
6. **Chase music and sounds (FR49, NFR14).** A chase loop `mus_pitchfork_panic` (OGG, looping, 60–120 s, goofy "panic", never scary or babyish) plays because `pitchfork_panic.tres` sets `music_id = &"mus_pitchfork_panic"`. `sfx_brain_pickup` gets its own file (no longer the bonk WAV). `sfx_dust_cloud` plays once when the caught outro starts; `sfx_escape` (a bush rustle with a "whee") once when the escape dive starts. All through `AudioManager` (the level's `play_sfx` seam), generated by `tools/gen_audio.gd` (CC0 by authorship), each file with exactly one row in `assets/audio/CREDITS.md`; mix rules hold (music under every effect but the tick, the tick quietest).
7. **Approval gates.** Smuck approves the new sheets (Gate 1, before they are wired), the in-game look (Gate 2) and the listen (Audio gate); each answer verbatim with the date in `## Art Approval` / `## Audio Approval`. The **Moonlit Village readability checklist** and the **chase listen checklist** (Dev Notes) are filled in pass/fail.
8. **No regressions.** The chase model, the camera at x 384, one step per key in the key's call, pickups, brains, the catch-before-timer rule, both outros' timings and results, the +10/+35 bonuses, the run RNG drawing exactly twice, Zombie Run and Horde Rush (their art and the MVP/Horde audio files byte-identical) all behave as after 8.5. Pitchfork Panic stays `available = false` (8.7 flips it). Full GUT suite green.

### Design decisions made for this story (follow them; record any change and why)

- **Reuse `SunnyVillageBackdrop` as is.** It is a generic 4-layer, 640 px wraparound parallax (`Clouds/Far/Near/Ground`, factors 0.1/0.25/0.5/1.0) driven by `_set_zombie_x`; the 8.3 test already asserts the ground offset through it. Only textures change. Renaming it (`ParallaxBackdrop`) would touch Zombie Run for no behaviour change: deferred to Epic 10, which adds four more backdrops.
- **A static moon.** A `Moon` child of `%Backdrop` outside the named layers never moves (the script moves only the four layers). A moon that stays put while the street scrolls is how night skies look, and it keeps `art-moon` out of the wrapping layers.
- **The mob is a scene with 4 members, origin = the front member.** All the 8.3/8.5 logic reads the logical mob position and `get_mob_screen_rect()`; keeping the origin at the front feet means no logic changes. The back member at −42 px keeps the whole mob on screen at gap 19.9 (the existing rect test).
- **Recolour = clothes-only legend swap**, mask and ink identical (the flash precedent, `test_flash_is_a_recoloured_walk`). That is literally "2 base sprites recolored" (GDD Reuse) and keeps Epic 10.4 reuse cheap.
- **Pitchforks upright, torches up, nightcaps.** NFR10 and the card ("farm tools held straight up, never aimed at anyone"). The comedy: sleepy villagers in pyjamas chasing a zombie who just wanted brains.
- **The hint replaces the glow.** A `GradientTexture2D` with alpha is a gradient and an off-palette blend (style sheet section 5 bans both; 8.3 said "final art in 8.6"). Sliding a palette sprite in by whole px carries the same "how close" signal with no alpha.
- **Frames, not transforms.** The 8.5 wobble (scale 0.9–1.1), the bush squash and the −12° tilt were fine on code-drawn shapes but resample pixel art into uneven, off-grid pixels. The sprite versions step frames and move by whole px. The fade layer (runtime alpha on a `night` rect, like the Router's) stays: it is a screen fade, not art.
- **A 48×48 effect frame** for the dust cloud and the bush: they must cover the zombie and the front mob member at the catch (two 32 px figures overlapping). 48 is the style sheet's existing brute size; record it as "effects" in section 3.
- **Stars are `parchment`, not candy-yellow.** Candy-yellow is reserved for "look here now" (the end label uses it); the stars are decoration.
- **Three sounds play in `on_run_ending()`'s call**, behind the existing repeat guard, never from a tween callback: once per run, deterministic, and freeing the level mid-outro can't fire one late.
- **The chase loop is a separate render path**, so `mus_menu`, `mus_zombie_run` and `mus_horde_rush` stay byte-identical (6.6 rule).

### Architecture and rules

- Godot **4.7.2**, GDScript only, GUT **9.7.1**. Static typing everywhere (`untyped_declaration` is an Error), typed arrays/dicts/loop vars, tabs, `##` docs that say why, LF endings, `snake_case` files, `PascalCase` classes.
- **ADR-1:** the level never reads input, the clock or `PlayerData`; it may call `AudioManager` through the `play_sfx` seam. RunFrame plays the music from `music_id`.
- **Logic leads, visuals chase; never `await`** in key or end paths. Animations react to `on_run_started`/`on_run_ending`, never to sprite positions.
- No GDD number as a literal (timings stay in the config); layout and look values may be consts with a doc saying so.
- Art: code-authored only via the tool; palette only; no gradients, glows, soft shadows, anti-aliasing; `candy-yellow` focus-only, `stamp-red` stamp-only, `art-moon` moon-only.
- Audio: OGG looping music; 16-bit mono WAV SFX normalised to `FILE_PEAK`, no leading silence, start/end at zero (`test_effect_source_files_follow_the_spec` covers every `SFX_IDS` entry).
