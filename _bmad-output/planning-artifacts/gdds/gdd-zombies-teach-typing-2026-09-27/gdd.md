# Zombies Teach Typing - Game Design Document

**Author:** Smuck
**Game Type:** General (educational typing arcade), with a custom Educational Typing Specific Design section
**Target Platform(s):** Web (HTML5, primary); Windows desktop (fallback)

---

## Executive Summary

### Core Concept

Zombies Teach Typing is a goofy typing tutor for kids aged 6–13, in the spirit of *Mario Teaches Typing*, with one twist: **the kid is the zombie.** Three short, standalone, replayable lessons each put a different game on the same typing curriculum:

| Level | Typing content | Length | Mood | The zombie… |
|---|---|---|---|---|
| **Zombie Run** | Single lowercase letters | 2:00 | Calm | bonks brain blocks and hugs villagers into a conga line |
| **Horde Rush** | Lowercase words | 3:00 (was 5:00, Story 6.7) | Rising pressure | sends a copy of itself down a lane for every word, at a house guarded by one pacing defender |
| **Pitchfork Panic** | Paragraphs with capitals, punctuation, numbers | Until caught, max 5:00 | Panic | flees a torch-and-pitchfork mob, one character at a time |

Every correct key makes the zombie do something mischievous. A wrong key simply does nothing. Every run ends on a chalkboard report card, and the brains earned buy hats and pets in the **Crypt Closet**.

**Core fantasy:** *You're a lovable cartoon zombie, and the better you type, the more mischief you get up to.*

**Player experience:** kids walk away feeling *clever and a bit mischievous*, never drilled or judged. Parents see a practice tool their kid chooses to open.

### Target Audience

- **Primary:** kids aged 6–13 learning or improving touch typing on a family computer or laptop with a physical keyboard, in 5–15 minute sessions (after school, before dinner). Skill does not track age: a fast 8-year-old and a beginner 13-year-old must both be served, and neither is ever labeled.
- **Secondary:** parents (possibly teachers) who want a friendly practice tool with a simple view of progress.
- **Reading level:** all UI text uses words a 6-year-old can read. Zombie slang ("Brainsss") appears only in voice and flavor, never in menu labels.
- **Distribution:** friends and family via a shared web link. No commercial goal.

### Unique Selling Points (USPs)

1. **The player is the zombie**, a rare framing for a kids' typing game. Every reward is cartoon mischief (hugs, conga lines, sieges), never violence.
2. **Invisible adaptive curriculum** *(post-MVP)*. A placement run, then a rolling WPM average, silently scopes which keyboard rows and word lengths appear. There is no difficulty menu, no rank and no "demotion", which also makes it sibling-proof and bad-day-proof.
3. **The curriculum is built into the structure:** letters → words → paragraphs across levels, and home → top → bottom row across difficulty.

These are differentiators, not moats. The real edge is charm and execution.

## Goals and Context

### Project Goals

1. **Ship the MVP as a shareable web link.** It contains the main menu, Zombie Run, the report card, a Crypt Closet with 1 hat and 1 pet, the welcome bonus, and a single local zombie save.
2. **Validate the core hypothesis:** *is typing as a goofy zombie fun enough that a kid chooses to play a second run, and to earn a hat?*
3. **Learn the BMAD/BMGD workflow end to end** (brief → GDD → architecture → epics → stories → build) on a real, finishable project.
4. **Deliver the full vision incrementally after the MVP:** Horde Rush, adaptive difficulty, Pitchfork Panic, the full Closet, then art variety and trends. Each is a separate shippable update.

### Background and Rationale

A passion project the author has held for a few years, built by one developer on occasional weekend mornings with no deadline. *Mario Teaches Typing* proved the structure (level select, finger-guide gloves, report card). *Plants vs. Zombies* proved that zombies can be goofy and kid-safe. *The Typing of the Dead* proved that zombies and typing work, but for adults and with a horror tone. Nobody lets a kid **be** the zombie. Art is code-generated by Claude, which caps visual fidelity at a clean 90s pixel style. That style suits the MTT reference.

## Core Gameplay

### Game Pillars

1. **You're the goofy zombie.** The player is the zombie in every level and every screen, including the report card and menus. All "violence" is cartoon: hugs, melting, fleeing, dust clouds. *Steers:* every reward animation, every fail state, every defender weapon (food and toys, never guns). The tone is goofy, never babyish: no toddler songs, and humor that lands for a 13-year-old and never scares a 6-year-old.
2. **Typing is the only skill.** A run asks for nothing but correct keystrokes: no lanes to pick, no strategy, no mid-run menus. A wrong key blocks progress and never punishes (no lost brains, no lost conga zombies, no health). *Steers:* no mechanic may add a non-typing decision; failure costs time, never stuff.
3. **Adapts to skill, invisibly** *(post-MVP system; MVP saves the data)*. Difficulty comes from measured WPM, never from age or a menu, and the kid never sees it change. *Steers:* no difficulty labels, ranks or "easy mode" anywhere in the UI; the only difficulty dials are keyboard rows, word length and (in Pitchfork Panic) punctuation richness, never enemy speed.
4. **Small, classic and finishable.** 90s sprites, one shared HUD and report card frame, variety through art rather than rules. *Steers:* a level never changes its rules between runs; new ideas go to Out of Scope by default.

### Core Gameplay Loop

**Moment-to-moment loop (every keystroke, all levels):**

1. **Read.** The target letter or word sits in a fixed spot at the bottom of the screen, and the green zombie hands light the finger to use. *(Pillar 2)*
2. **Type.** A correct key is accepted instantly. A wrong key does nothing except add to the error count. *(Pillar 2)*
3. **Reward.** Every correct key triggers visible mischief: a brain bonk, a hug into the conga line, a zombie spawned, a step away from the mob. *(Pillar 1)*
4. **Next target.** The next target is active immediately; animations never delay typing. → back to 1.

**Session loop (each run):** pick a level → timed run → chalkboard report card (keys, errors, WPM, accuracy, time, brains) → **Play Again** or **Menu**.

**Meta loop:** brains → Crypt Closet → buy and wear a hat or pet → see the hat on the zombie in every level and the pet in the HUD during typing → play again to afford the next one. *(Pillar 1: the reward is always on screen.)*

**Why the 100th run:** the Closet always has a next item (18 total, 3,600 brains). The report card shows a personal best to beat. Art themes rotate *(post-MVP)*. And the typing itself gets visibly faster: more villagers in the line, bigger hordes, longer escapes.

### Win/Loss Conditions

There is no game-level win or loss. Levels are standalone and replayable forever. Each level after the first opens once the previous level has one completed run (see Level Progression); nothing else is ever locked. Per run:

| Level | Run ends when | "Win" framing | Loss? |
|---|---|---|---|
| Zombie Run | Timer reaches 0:00 | Always a completed lesson; dance and report card | None |
| Horde Rush | Timer reaches 0:00 | Always completed; brains = zombies that reached the house | None; zombies stopped by the defender simply earn nothing |
| Pitchfork Panic | Mob catches the zombie **or** 5:00 survived | Surviving 5:00 = **"Escaped!"** (+25 brains) | Being caught ends the run; all brains collected are **kept** |

Quitting mid-run (pause → Quit) keeps brains already collected, awards no completion bonus, and does **not** record the run in stats history.

## Game Mechanics

### Primary Mechanics

#### M1. Blocking typing input (all levels)

- One **active target character** exists at any time.
- **Correct key:** accepted with zero delay. The next target character becomes active in the same frame, and feedback (animation, sound) plays concurrently. Animation length never limits typing speed: at 60+ WPM (≈ 5 keys/s), overlapping animations are allowed or skipped.
- **Wrong printable key:** no progress, no world change, error count +1, a soft "bonk" tick sound (max 1 per 150 ms), and the target character shakes for 0.2 s. There is no other penalty.
- **Ignored keys (never errors):** Shift (except as part of a capital), Ctrl, Alt, Meta, arrows, function keys, Tab, Backspace, Enter, Caps Lock. In Zombie Run and Horde Rush, Space is also ignored.
- **Case:** Zombie Run and Horde Rush are lowercase-only and accept a letter regardless of Caps Lock or Shift. A "Caps Lock is on" hint appears after 3 consecutive capitals. Pitchfork Panic is case-sensitive.
- **Run timer start:** the timer starts on the first correct keystroke, not on scene load. Before that, the HUD shows the first target and the label "Type the letter to start!" (or "word" / "text").

#### M2. Stats measurement (all levels)

| Stat | Definition |
|---|---|
| Keys Typed | Count of correct keystrokes (a capital counts as 1) |
| Errors | Count of wrong printable keystrokes |
| Accuracy | Keys Typed ÷ (Keys Typed + Errors), whole-number % |
| WPM | (Keys Typed ÷ 5) ÷ run minutes. In Horde Rush, each completed word adds +1 for the implied space. Whole number. |
| Lesson Time | Run duration from the first correct key to the end, m:ss |
| Brains | Brains earned this run, including bonuses (bonuses shown as a separate "+N bonus" line) |

Live HUD WPM updates once per second and appears only after 5 s of run time, to avoid early spikes.

#### M3. Pause

- **Esc** (or clicking the pause button) pauses: the timer stops and the world freezes. Options: **Resume** / **Quit to Menu**, plus the Music and Sound toggles.
- The game auto-pauses when the browser tab or window loses focus.
- Resuming from pause shows a 3-2-1 count (0.5 s per number) before input is accepted again.

#### M2b. Shared HUD (all levels)

The bottom band (104 px of the 360 px logical height) always holds, left to right: the **pet slot** · the **target area** (a letter, a word or a 2-line text window, always in the same spot) with the **zombie hands** below it · a stats column with **Timer**, **Keys Typed**, **WPM** and **Errors**, with the **brain counter** (this run's brains) beside it in every level. A **pause button** sits in the top-right corner of the playfield.

#### M4. Brains and the Crypt Closet (meta)

- Brains are the single currency. Only cosmetics can be bought; brains never gate learning content (level order is the only gate, see Level Progression).
- Earning rates per level are in *Economy and Resources*. Brains persist in the save and are never lost.
- **Cosmetic slots:** 1 hat (drawn on the zombie in every level, on all Horde Rush copies and on Professor Zombie) and 1 pet (sits in the HUD next to the target, with an idle animation, and also appears on the report card). Either slot can be empty.

#### M5. Welcome bonus and first purchase

- After the **first completed run ever**, the report card is followed by a "Welcome gift!" card: **+100 brains**, with one button, "Open the Crypt Closet".
- In the Closet, an arrow points at the first affordable item → **Buy** → confirm → **Wear**. The tutorial ends after the first item is worn, or when the kid leaves the Closet. It is shown once per save.

### Controls and Input

| Context | Keyboard | Mouse |
|---|---|---|
| Gameplay | Letter, number, punctuation, Space, Shift keys per level; Esc = pause | Pause button only |
| Report card | Enter = Play Again, Esc = Menu (both ignored for the first 1.0 s to stop mash-through) | Click buttons |
| Menus / Closet | Arrow keys move focus, Enter selects, Esc goes back | Click |
| Title screen | Any key or click starts (also unlocks browser audio) | Click |

- **Layout:** US QWERTY assumed for the finger guide [ASSUMPTION: A1 US QWERTY]. Matching uses the typed **character**, so other layouts can still play, but the hands' finger hints may be wrong.
- **Browser capture:** keys that trigger browser actions must be swallowed during gameplay: Space (scroll), `'` and `/` (Firefox quick-find), Backspace, Tab. Ctrl+W and other OS or browser shortcuts cannot be blocked and are not required to be.
- **Hardware:** a physical keyboard is required. Touch devices are out of scope.

## Educational Typing Specific Design

### Curriculum Model

The curriculum runs along two axes:

- **Across levels (content type):** letters (Zombie Run) → lowercase words (Horde Rush) → real writing with capitals, punctuation and numbers (Pitchfork Panic). The level menu doubles as a skill ladder: each level opens after one completed run of the one before it.
- **Across difficulty (keys in play):** home row → + top row → + bottom row, then longer words and richer punctuation. See *Adaptive Difficulty*.

| Row | Keys (lowercase levels) |
|---|---|
| Home | `a s d f g h j k l` |
| Top | `q w e r t y u i o p` |
| Bottom | `z x c v b n m` |

Punctuation and numbers appear only in Pitchfork Panic. **MVP:** Zombie Run uses all 26 letters on every run (no scoping). Stats are saved so scoping can be added later without changing the save format's meaning.

### Input & Judgment Model

- Judgment is binary: correct or error. There are no timing windows, combos or multipliers, because speed is rewarded naturally by doing more in the same time (Pillar 2).
- **Target selection (Zombie Run):** letters are drawn from a shuffled bag of the active letter pool. Every letter appears once before any repeats, and the same letter never appears twice in a row across bag boundaries.
- **Per-key tracking:** for every expected character, the run records attempts and errors. For example, "expected `f`: 14 attempts, 3 errors (typed `g` ×2, `d` ×1)". This feeds post-MVP adaptive difficulty and the trends screen. It is never shown to the kid in the MVP.

### Finger Guide (Green Zombie Hands)

- Two cartoon green zombie hands sit in the bottom HUD in every level. The finger for the **next** character glows (a brighter green plus a pulsing outline, so the cue doesn't rely on hue alone) and moves along as the kid types words and paragraphs.
- **Finger map (standard touch typing):**

| Finger | Left hand | Right hand |
|---|---|---|
| Pinky | `1 q a z`, Left Shift | `0 p ; / ' - =`, Right Shift, Enter |
| Ring | `2 w s x` | `9 o l .` |
| Middle | `3 e d c` | `8 i k ,` |
| Index | `4 5 r t f g v b` | `6 7 y u h j n m` |
| Thumbs | Space | Space |

- **Capitals and shifted symbols** (Pitchfork Panic): light **both** the character's finger and the **opposite hand's** pinky on Shift.
- **Home-row anchors:** the `f` and `j` fingertips show a small bump mark at all times.

### Adaptive Difficulty *(post-MVP; MVP stores the data)*

- **Input signal:** the rolling average WPM of the most recent 1–5 completed runs across all levels. Quit runs don't count. The kid never sees the value or the tier.
- **Placement:** a save's very first Zombie Run uses all 26 letters. Its WPM sets the starting tier.

| Tier | Rolling WPM | Keys in play | Horde Rush word length | Pitchfork Panic text |
|---|---|---|---|---|
| 1 | < 8 | Home row | 2–4 (widened to 2–4, Smuck, Story 7.3 review 2026-10-08) | Generated sentences from row-filtered words; capital first letter, ends with `.` |
| 2 | 8–14 | Home + top | 3–4 | Same, plus `,` |
| 3 | 15–21 | All letters | 3–5 | Authored paragraphs using `. , ! ?` |
| 4 | 22–29 | All letters | 4–6 | + numbers and apostrophes |
| 5 | 30+ | All letters | 5–8 | Full authored paragraphs, any punctuation in the set |

- **Hysteresis:** a tier goes **up** as soon as the average reaches the next floor. It goes **down** only when the average drops **2 WPM below the current tier's floor** (e.g. tier 3 drops to tier 2 below 13 WPM).
- **Boundaries:** tiers compare against the unrounded average (14.5 is tier 2). A drop can skip tiers: once the average is below the current floor − 2, the tier is set to the tier whose range contains the average.
- [NOTE FOR DESIGNER: WPM is not fully comparable across levels (Horde Rush adds implied spaces; Pitchfork Panic includes Shift and punctuation). Review per-level WPM in saved history before Epic 7 and add per-level weighting if one level skews the average.]
- **What never scales:** Zombie Run pacing, the Horde Rush defender and the Pitchfork Panic mob. Difficulty is always a typing challenge (Pillar 3).
- **Zombie Run under tiers:** its letter pool follows the tier's rows. Tiers 3–5 all use 26 letters.

### Content: Word Lists & Paragraphs

- **Master word list:** about 1,500 kid-safe lowercase words, authored by Claude and cross-checked against the public-domain Dolch sight-word lists. It excludes scary, violent, rude or brand words. Smuck reviews the list by hand once before first use.
- **Tagging (build-time, offline):** every word is tagged with the rows it needs (home, top, bottom) and its length. A tier's word pool = words using only the tier's rows and within its length band. Tier 1 pool check: at least 40 home-row words of 2–4 letters (widened to 2–4, Smuck, Story 7.3 review 2026-10-08) (e.g. *dad, sad, ask, all, lad, gag, had, flag*).
- **Paragraphs:** about 40 original passages, goofy and zombie-themed in plain words, 2–4 sentences, 150–400 characters each, tagged tier 3, 4 or 5 (about 13 per tier). Tiers 1–2 generate sentences at runtime from their word pool: 4–7 words, capital first letter, end punctuation.
- **Selection:** no passage repeats until all passages in the tier have been used (per save).

### Session Length & Accessibility

- **Session target:** 5–15 minutes = 2–6 runs. The longest run is 5:00.
- **Readability:** the target character or word (letter and word levels) is at least 32 px tall at the 640×360 logical resolution. Pitchfork Panic's 2-line paragraph text is at least 24 px, so both lines and the zombie hands fit the 104 px HUD band. UI text is at least 16 px.
- **Color:** finger and typed-text states use brightness plus shape or underline, never color alone.
- **Audio:** separate Music and Sound toggles on the main menu and the pause panel, saved. The game is fully playable muted.
- **No time pressure outside runs:** menus, the report card and the Closet have no timers.

## Progression and Balance

### Player Progression

1. **Skill (the real progression):** WPM and accuracy rise, which shows up as more mischief per run and as report-card personal bests. A **"New best!"** stamp appears on the report card when a run beats that level's best WPM (after the first run).
2. **Curriculum** *(post-MVP)*: rows unlock silently as the rolling WPM rises.
3. **Collection:** 18 cosmetics, 3,600 brains total. This is the long-term visible goal.

### Difficulty Curve

- **Across levels:** calm → rising pressure → panic, in step with letters → words → paragraphs. Each level opens after one completed run of the previous one; after that, players choose freely between open levels.
- **Within a run:** Zombie Run is flat by design (a warm-up and measuring stick). Horde Rush tension comes from the kid's own speed against a fixed defender. Pitchfork Panic's mob accelerates, so every run ends in a crescendo.
- **Across sessions:** handled by adaptive difficulty *(post-MVP)*. The MVP difficulty is the full keyboard for everyone. [NOTE FOR DESIGNER: watch 6-year-old playtesters in the MVP. If the full keyboard frustrates them, pull forward a simple home-row-only first run.]

### Economy and Resources

**Principle:** every level pays roughly the same brains per minute of play (target: within ±20% of Zombie Run at the same WPM), so no level becomes the one kids grind.

| Level | Earning | Bonus | ~Brains/run at 10 WPM | ~at 20 WPM |
|---|---|---|---|---|
| Zombie Run | 1 per brain block; brain blocks are 1 in every 4 targets | +10 on completion | 35 (≈17/min) | 60 (≈30/min) |
| Horde Rush | Per zombie reaching the house: small 1, medium 2, big 3 (≈1.7 average in the 3–5 letter band) | +30 on completion (tuned in Story 6.7, 2026-10-08, for the 3:00 run) | ≈50 at 37% arriving (≈17/min) | ≈92 at 60% arriving (≈31/min) |
| Pitchfork Panic | Brain pickup every 10–30 steps (uniform random), 5 brains each (≈0.25 brains per character, like brain blocks) | +10 on every finished run; +25 if **Escaped!** | ≈40 (2.4 min run, ≈17/min) | ≈160 (escape, ≈32/min) |

(At 5 WPM: Zombie Run ≈ 22 ≈ 11/min; Pitchfork Panic ≈ 17 in a 70 s run ≈ 15/min.) [NOTE FOR DESIGNER: Horde Rush runs about 30% under parity at 5–10 WPM; raise arrival brains or the completion bonus during the Epic 6 tuning pass.] (Resolved in Story 6.7, 2026-10-08: the run was shortened to 3:00 and the completion bonus went 25 → 30 (10 brains/min, as 50 over 5:00 would be), arrival brains unchanged; the headless sim puts Horde Rush at +8 % / −6 % / +2 % of Zombie Run at 5 / 10 / 20 WPM, ≈12/min at 5 WPM.)

- **Welcome bonus:** 100 brains, once per save, after the first completed run.
- **Prices:** Closet row 1 = 100, row 2 = 200, row 3 = 300. Full set = 3,600.
- **Pacing check:** at 10 WPM, the full collection ≈ 100 Zombie Runs ≈ 26 ten-minute sessions (about 2 months at 3 sessions/week). At 20 WPM, ≈ 15 sessions. In the MVP: welcome bonus (100) + first run buys item 1; item 2 is about 3 runs away. This is the core hypothesis test.
- **No sinks other than cosmetics.** No loss, no decay, no refunds (none needed; items are never sold back).

**Crypt Closet catalogue (full vision; MVP items in bold):**

| Price | Hats | Pets |
|---|---|---|
| 100 | **Pumpkin hat**, Witch hat, Bunny ears | **Cute ghost**, Black cat, Spider |
| 200 | Santa hat, Leprechaun hat, Valentine heart headband | Orange cat, Bat, Crow |
| 300 | New Year's top hat, Pirate hat, Golden crown | Wolf-dog, Floating eyeball, Brain buddy (a tiny walking brain) |

The MVP Closet shows both 3×3 grids. The Pumpkin hat and Cute ghost are live; the other 16 slots show a locked "?" silhouette labeled "Coming soon".

## Level Design Framework

### Level Types

#### Level 1: Zombie Run (MVP)

*Name kept (decision 2026-09-27) despite the overlap with Pitchfork Panic, the actual chase. The menu art and the calm mood make the difference clear.*

- **Content:** single lowercase letters (MVP: all 26). **Length:** 2:00. **Mood:** calm, sunny, cheerful.
- **Scene:** a side-scrolling backdrop. Targets are spaced **48 px** apart, and the next **3 targets** are visible ahead, each showing its letter. The active one bobs and has a down-arrow, and its letter matches the HUD target.
- **Movement:** while waiting for input, the zombie ambles forward at a constant 24 px/s and stops 24 px before the active target to idle. On a **correct key**, the target resolves instantly (its hop or hug animation plays), and the zombie **scoots** to the next target's approach point in 0.15 s. Scoots chain, so a fast typist races along and the walk never caps typing speed. Targets never scroll away.
- **Target mix:** in each group of 4 targets, 1 is a **brain block** and 3 are **villagers** (shuffled per group).
  - **Brain block** (floating 48 px above ground): correct key → the zombie hops (0.35 s) and bonks it from below → a brain pops out (+1). 20% chance of a "Brainsss…" voice line.
  - **Villager** (standing on the path, waving): correct key → the zombie hugs (0.4 s) → the villager poofs into a **party-hat zombie** and joins the conga line.
- **Conga line:** party-hat zombies trail the zombie in a bobbing line. At most 12 are drawn; beyond that a "×N" badge rides the last follower. The line never shrinks during a run.
- **End:** at 0:00, input stops, the zombie and conga line dance for 2.0 s, then the report card appears.
- **Pacing never scales** (not even post-MVP). Only the letter pool follows tiers.

#### Level 2: Horde Rush (post-MVP)

- **Content:** lowercase words (pre-adaptive build: fixed 3–5 letter band). **Length:** 5:00 (3:00 since Story 6.7, 2026-10-08: playtest "5 minutes felt too long"). **Mood:** rising pressure.
- **Field:** 5 horizontal lanes. Zombies enter at the left, and the defended house fills the right edge. The defender paces up and down the lanes in front of the house.
- **Word loop:** one word is shown at the bottom. Typed letters turn green and the next letter is underlined. The word completes on its last letter (no Space needed). A zombie copy of the player (wearing their hat) spawns in a **random lane**, and the next word appears instantly.
- **Size classes:**

| Word length | Zombie | Crossing time | Hits to stop | Brains on arrival |
|---|---|---|---|---|
| ≤ 3 | Small, quick | 8 s | 1 | 1 |
| 4–5 | Medium | 10 s | 2 | 2 |
| ≥ 6 | Big brute | 13 s | 3 | 3 |

- **Defender** (starting values [NOTE FOR DESIGNER: tune in playtest] (resolved: tuned in Story 6.7, 2026-10-08)): paces continuously at 1 lane per 1.5 s (was 0.6), reversing at the top and bottom lanes. When level with a lane that has a zombie, it throws at the front-most zombie in that lane (2.4 s cooldown, was 0.8; the projectile takes 1.2 s to cross the field, was 1.0). Hit → the zombie flashes red for 0.15 s. Final hit → it falls and melts into the ground over 0.6 s.
- **Tuning target:** about 40% of zombies arrive at 10 WPM and about 70% at 30 WPM (Story 6.7 sim, 2026-10-08, 3:00 run: 37% and 68%). Adjust defender numbers until playtests hit these, and adjust arrival brains until the economy parity target is met.
- **Arrival:** the zombie shuffles into the door → "Brainsss" (throttled) → +brains pop.
- **House + defender pairs** (random per run): Farmhouse + Farmer throwing tomatoes; Castle + Knight with suction-cup darts; Beach Hut + Lifeguard with water balloons. There are no guns.

#### Level 3: Pitchfork Panic (post-MVP)

- **Content:** paragraphs with capitals, punctuation and numbers (tier-based, see Adaptive Difficulty). **Length:** until caught, max 5:00. **Mood:** goofy panic.
- **Text display:** the bottom target area shows a 2-line window. The current line has typed characters in green and the next character underlined; the next line is dimmed. Paragraphs flow continuously. Passages are joined by a single Space: after the last character of a passage the kid types Space (both thumbs light), and the next passage starts on the next line. The joining Space counts as a typed key.
- **Movement model:** each correct character moves the zombie **1 step** forward. The torch-and-pitchfork mob chases from the left.
  - Start gap: **15 steps**.
  - Mob speed is expressed as a WPM-equivalent (1 WPM-eq = 5 steps/min). It starts at **4 WPM-eq** and gains **+1 WPM-eq every 10 s**.
  - Resulting run lengths: ≈ 70 s at 5 WPM, ≈ 2.4 min at 10 WPM, and ≈ 19+ WPM typically escapes.
  - [NOTE FOR DESIGNER: tune start gap and acceleration in playtest.]
- **Screen:** the camera keeps the zombie at 60% of screen width. The mob's distance is always readable, and the mob appears on screen once the gap is under 20 steps.
- **Brain pickups:** placed along the path every 10–30 steps (uniform random, counted from the previous pickup), and the zombie collects each one by typing forward (5 brains). Spawning by distance, not time, makes pickups pay per character typed.
- **Finished-run bonus:** +10 brains for any caught or escaped run.
- **Caught:** the mob reaches the zombie → input stops → cartoon dust cloud (1.5 s) → the zombie sits dazed with circling stars and a "Got you!" label (1.0 s) → fade (0.5 s) → report card. All brains are kept.
- **Escaped!:** at 5:00 the zombie dives through a hedge, gate or bush (1.5 s) → "Escaped!" → report card, with the +25 bonus.
- **Chase settings** (random per run): Moonlit Village, Cornfield Path, Spooky Forest Bridge. The mob sprites are reused across settings.

### Level Progression

- The main menu is a *Mario Teaches Typing*-style level select.
- **Level unlocks** *(post-MVP, UX D12)*: Horde Rush opens after the first Zombie Run that reaches 0:00; Pitchfork Panic opens after the first Horde Rush that reaches 0:00. Quit runs never unlock. An unlock is saved permanently and plays a one-time unlock moment on the menu. Unlocks gate access only; no difficulty labels are shown (Pillar 3).
- In the MVP, Horde Rush and Pitchfork Panic appear with a "Coming soon" sign and cannot be selected. "Coming soon" takes precedence over Locked, so no lock ever shows in the MVP.
- **Art rotation** *(post-MVP)*: each level picks one of its 3 themes at random each run and avoids repeating the previous theme. Rules never change with the theme.
- **Zombie Run themes:** Sunny Village Green (MVP, the only theme at launch), Pumpkin Patch Farm, Snowy Town.

### Screens & Flow

`Title ("Click or press any key") → Main Menu → [Level → Report Card → (Welcome Gift → Crypt Closet, first time only) → Play Again | Menu] | Crypt Closet`

- **Main Menu:** title logo, the player's zombie (wearing the hat, pet beside it), the brain counter, 3 level cards, a Crypt Closet button, and Music, Sound and Fullscreen toggles.
- **Report Card (all levels):** a chalkboard showing Keys Typed, Errors, WPM, Accuracy, Lesson Time and Brains Collected (+ bonus line), plus a "New best!" stamp if earned. **Professor Zombie** (the player's zombie in a graduation cap and gown, with pet) points at the board. Buttons: **Play Again** and **Menu**.
- **Crypt Closet:** hat grid and pet grid (3×3 each, price by row), the brain counter, and a preview of the zombie wearing the selected item. Item states: Locked-coming-soon / Can't afford ("Need N more") / Buy / Wear / Wearing (click to take off).

## Art and Audio Direction

### Art Style

- **Look:** a bright, readable early-90s pixel-art feel inspired by *Mario Teaches Typing*. The zombie is a cartoon with a big goofy face and no gore, no body-part gags and no blood. Defeat is always melting, dust clouds or dizzy stars.
- **Production:** all art is generated by Claude as code-authored pixel art or SVG rasterized to pixel sprites. Consistency comes from standards set **before** content:
  - Logical resolution **640×360**, scaled to fill the browser window (fractional scaling with nearest-neighbor filtering, so pixels may be slightly uneven at non-whole sizes). A **Fullscreen** toggle on the main menu gives the biggest picture.
  - One shared palette of at most **32 colors**; every sprite uses it.
  - Characters are 32×32 px (brutes 48×48); tiles 16×16; 1 px dark outline on characters and props.
  - Animations use 2–6 frames at 8–12 fps.
  - Cosmetics are drawn as overlays anchored to a head point and a pet slot, so any hat fits every zombie pose.
- **Reuse:** party-hat zombies are the villager sprite recolored plus a party hat; Horde Rush copies are the player sprite plus scaling for size classes; mob members are 2 base sprites recolored.
- **Risk gate:** prototype the palette, the zombie and one villager first, and approve them before producing any other art.

### Audio and Music

- **Restraint:** zombie groans play at random every 3–8 s, never on every keypress, and are muted within 2 s of a voice line. The "Brainsss…" line has a 20% chance on a brain collect, with at least 8 s between lines.
- **SFX set:** brain bonk, hug-poof, wrong-key tick (quiet), zombie spawn (Horde Rush), defender throw and hit, melt, dust cloud, pickup, purchase jingle, report card chalk-scratch and chime, UI click.
- **Music:** one light, bouncy menu loop and one loop per level (calm / march / chase), each 60–120 s, mixed below SFX so it doesn't grate on older kids.
- **Sources:** CC0 or similar free libraries, or simple generated sounds [ASSUMPTION: A5 free audio licensing]. Voice lines could be recorded by the author.
- **Web:** audio starts only after the first click or key on the title screen.

## Technical Specifications

### Performance Requirements

- **Frame rate:** a steady 60 FPS in Chrome, Edge and Firefox (desktop) on a 2018-era family laptop with integrated graphics [ASSUMPTION: A3 target hardware]. MVP measurement: a full 2:00 Zombie Run with 12 conga followers drawn, using the browser performance tools, with no frame over 33 ms. Post-MVP: the same check over a full Horde Rush run, plus a stress scene with 30 zombies on screen.
- **Input feedback:** a correct keystroke produces visible feedback (target advance plus effect start) on the next rendered frame (≤ 17 ms at 60 FPS).
- **Load:** first load to the title screen ≤ 10 s on a 25 Mbit/s connection; repeat loads (cached) ≤ 3 s. Total download ≤ 40 MB.
- **Save integrity:** no data loss across 10 consecutive browser reloads and 10 tab closes mid-menu. The save is written at run end, on quitting a run (brains only), after each purchase or equip, and on settings changes.

### Platform-Specific Details

- **Engine:** Godot 4.7 with the Compatibility renderer, GDScript only (C# web export is unsupported).
- **Web (primary):** HTML5 export that runs on **plain static hosting with no special server headers** [ASSUMPTION: A2 hosting on itch.io or GitHub Pages]. Desktop Chrome, Edge and Firefox are supported; Safari is best-effort; mobile and touch are unsupported.
- **Saves:** stored in browser storage per browser and per device. Clearing site data erases progress, which is accepted for a family project. No accounts, no network, no analytics.
- **Windows (fallback):** a desktop export, used only if a web constraint blocks a feature. It uses the same save contents.
- **Save contents (single zombie in the MVP):** brains; owned items; equipped hat and pet; welcome-bonus-claimed flag; tutorial-seen flag; placement-done flag; level unlocks (post-MVP: per level, unlocked + unlock-moment-seen + first-chosen); current tier (post-MVP); settings (music, sound); per-level best WPM; **run history** (last 500 runs: date/time, level, duration, keys typed, errors, WPM, accuracy, brains earned, letter pool or tier, per-key attempts and errors, end reason). Profiles post-MVP will hold one such record per zombie.

## Success Metrics

### Technical Metrics

- 60 FPS sustained and ≤ 17 ms input feedback on the target laptop (see Performance Requirements).
- Zero save losses in the reload and tab-close test (10 + 10 cycles) on Chrome and Firefox.
- The MVP link loads and plays on at least 3 different family computers without help.

### Gameplay Metrics

This is personal scope, so the metrics are observed in playtests with kids in the author's circle [ASSUMPTION: A4 kid playtesters] and read from saved run history.

- **Core hypothesis (Pillar 1):** at least 2 of the first 3 kid playtesters (1 in Epic 5, the rest after the link is shared) start a second Zombie Run unprompted, and buy an item in their first session.
- **Return:** at least 1 kid opens the game again on a different day within a week, without being asked.
- **Typing is the only skill (Pillar 2):** median accuracy stays ≥ 85%. Lower accuracy suggests content that is too hard, or key-mashing.
- **Learning:** for a kid with 10+ runs, the average WPM of the last 5 runs beats that of the first 5.
- **Tone:** no playtester reports being scared, and no 11–13-year-old calls it "babyish" (asked directly after play).
