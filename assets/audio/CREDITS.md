# Audio credits

Every MVP sound is generated by `tools/gen_audio.gd` (Story 5.1, Gate A: all generated), so each is CC0 by
authorship; so are the Horde Rush sounds and march (Story 6.6). The music loops are rendered to WAV by that tool and encoded to OGG by `tools/encode_ogg.py`.
`tests/unit/test_audio_credits.gd` checks that every file under `assets/audio/` has exactly one row here.
